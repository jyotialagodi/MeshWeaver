# MeshWeaver

Zero-Dependency P2P Async Task Broker

## Project

MeshWeaver is a decentralized Python task broker developed according to the
Advanced Python Engineering project plan.

## Technology

- Python
- asyncio
- UDP/TCP sockets
- Kademlia DHT
- cloudpickle
- Gossip Protocol
- Heartbeat Monitoring
- TLS/SSL
- Rich CLI Dashboard
